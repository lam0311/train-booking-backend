TẦNG 04: DOMAIN LAYER (NGHIỆP VỤ CỐT LÕI)

VAI TRÒ CHÍNH:

Xử lý thuật toán Bitmask cốt lõi. Chuyển đổi các chặng tàu thành số nhị phân và kiểm tra ghế trùng bằng các phép toán bit tức thì.

NGUYÊN TẮC:

Độc lập hoàn toàn, không phụ thuộc vào thư viện ngoài hay cơ sở dữ liệu.

PHẠM VI:

4 chặng tàu nằm gọn trong 4 bit (giá trị từ 0 đến 15).

ĐẦU VÀO: Ga đi (0..3), Ga đến (1..4), Ghế hiện tại (0..15).
ĐẦU RA: Mặt nạ chặng (0..15), Trùng hay không (true/false).
TỆP TIN:
src/modules/bookings/domain/segment-mask.js
src/modules/bookings/domain/segment-mask.js JavaScript 
const TOTAL_SEGMENTS = 4;
const FULL_MASK = 15;

const buildSegmentMask = (fromIndex, toIndex) => {
    const segmentCount = toIndex - fromIndex;
    return ((1 << segmentCount) - 1) << fromIndex;
};

const hasConflict = (mask1, mask2) => {
    return (mask1 & mask2) !== 0;
};

const buildClearMask = (segmentMask) => {
    return FULL_MASK ^ segmentMask;
};

module.exports = { buildSegmentMask, hasConflict, buildClearMask };

6. Bốn Định Hướng Phát Triển Cho Pha Sau (Phase 2)

Các đề xuất thực tế để nhóm tiếp theo tiếp quản và mở rộng dự án.

HƯỚNG 1 // THUẬT TOÁN

Mở Rộng Tuyến Dài Hơn (BigInt)

Hiện tại hệ thống demo tuyến 5 ga (4 bit). Nhóm sau có thể mở rộng lên tuyến Bắc - Nam từ 20 đến 30 ga bằng kiểu BigInt của JavaScript (1n << n). Thuật toán Bitmask vẫn giữ nguyên logic và kiểm tra trùng chặng tức thì.

MỤC TIÊU: HỖ TRỢ TUYẾN 20-30 GA
HƯỚNG 2 // TRẢI NGHIỆM

Giữ Chỗ Tạm Thời Khi Thanh Toán

Khi khách chọn ghế, tạm giữ chỗ trong 10 phút để điền thông tin và thanh toán. Sử dụng Redis TTL (thời gian sống 10 phút) để tự động nhả ghế nếu khách không thanh toán, tránh hiện tượng giữ ghế ảo.

MỤC TIÊU: TRÁNH GIỮ GHẾ ẢO
HƯỚNG 3 // THỜI GIAN THỰC

Đồng Bộ Ghế Trống Thời Gian Thực

Sử dụng WebSocket hoặc Server-Sent Events (SSE). Khi có ai đó đặt ghế thành công, sơ đồ ghế trên màn hình của tất cả các khách khác đang xem chuyến tàu sẽ tự động đổi màu mà không cần bấm F5 tải lại trang.

MỤC TIÊU: ĐỒNG BỘ TOÀN HỆ THỐNG
HƯỚNG 4 // NGHIỆP VỤ

Trang Quản Lý Vé & Mã QR

Bổ sung trang xem lại lịch sử các vé đã mua (kèm mã QR soát vé để lưu vào điện thoại) và trang Quản trị viên để theo dõi lượng vé bán ra, tỷ lệ lấp đầy ghế theo từng chuyến tàu.
